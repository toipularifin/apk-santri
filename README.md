# Sistem Manajemen Pondok Pesantren (e-Pesantren)

Aplikasi manajemen Pondok Pesantren lengkap berbasis Python (Flask) dengan akun Admin, Guru, Pengurus, dan Orang Tua yang saling terhubung.

## Akun Default Login
- Admin: `admin` / `admin123`
- Guru: `guru1` / `guru123`
- Pengurus: `pengurus1` / `pengurus123`
- Orang Tua: `wali1` / `wali123`

## Cara Menjalankan
```bash
pip install -r requirements.txt
python app.py
```
